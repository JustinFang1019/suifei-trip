# 隨飛 SUIFEI

以「旅行意圖投資組合」為核心的多人旅行決策 MVP。使用者可以先建立個人組合，或先建立旅團並分享邀請連結；每位成員各自填寫日期、預算、出發機場、天數與旅行偏好，系統再產生最多三個共同答案。

## 已可使用的流程

- 建立個人旅行組合或多人旅團
- 產生專屬邀請碼與分享連結
- 加入旅團並保存個人旅行條件
- 以硬條件、平均偏好及最低滿意度計算團體交集
- 顯示最多三個目的地候選及取捨
- 保存全團目前選擇
- 帶入機場與日期至 Google Flights 做即時查票
- 在 Cloudflare D1 保存旅團、成員、條件與結果

## 價格資料原則

站內不顯示未經即時驗證的金額。候選結果提供帶日期與機場條件的外部航班搜尋連結，使用者在外部平台取得即時價格並完成購買。接入正式 GDS、OTA 或航空公司供應商 API 後，可在 `trip_candidates` 的驗價欄位保存供應商、總價、行李條件、購買 deep link 與驗證時間。

## 隱私與身份

- 網站公開可用，不需要 ChatGPT 或其他帳號登入。
- 第一次開啟時會在裝置上產生匿名識別碼，用於找回該裝置建立或加入的旅團。
- LINE Login 未來可作為跨裝置找回資料的選配功能，不會成為使用門檻。
- 成員精確預算不會出現在團體回應中；共同預算只顯示千元級距。
- 分享碼使用加密安全亂數產生，所有寫入與旅團成員檢查都在伺服器端執行。
